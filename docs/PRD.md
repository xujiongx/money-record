# 产品需求文档（PRD）

> 产品：家庭记账 · 版本：v1.0（MVP） · 状态：已实现 · 更新日期：2026-04-02

## 1. 文档信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 家庭记账（温暖小账本） |
| 技术形态 | Next.js 移动端视口 + Supabase |
| 家庭成员（种子） | 布布、一二 |

## 2. 背景与目标

### 2.1 背景

家庭日常收支分散、难以及时对齐；需要一款**两人共用**、**数据云端同步**、**以手机为主**的轻量账本。

### 2.2 目标

- 实时展示家庭总收入、总支出与结余。  
- 快速记账（收入/支出、分类、记录人、备注）。  
- 成员维度统计与可视化（分类占比、成员支出对比）。  
- UI 温暖友好（橙粉渐变、圆角、动效），多设备数据一致。

### 2.3 非目标（本期不做）

- 桌面端多栏布局、复杂预算与账单导入导出。  
- 多家庭切换、完整账号体系（可后续迭代）。  
- 独立开放 REST 对外 API。

## 3. 用户与场景

### 3.1 目标用户

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 家庭成员 | 布布、一二 | 随时记账、看汇总、看对方记的账 |
| — | 同一家庭共用一套数据 | 多端打开即可同步 |

### 3.2 用户故事

1. 作为**家庭成员**，我希望**打开首页就看到总收支和结余**，以便**快速了解家庭财务状况**。  
2. 作为**记账人**，我希望**选收入/支出、分类和记录人一键保存**，以便**几秒记完一笔**。  
3. 作为**成员**，我希望**在统计页看到钱花在哪、谁花得多**，以便**调整消费习惯**。  
4. 作为**用户**，我希望**另一台手机记账后我这边自动更新**，以便**不用手动刷新**。

## 4. 功能需求

| 编号 | 模块 | 需求描述 | 优先级 | 验收要点 |
|------|------|----------|--------|----------|
| F-01 | 仪表盘 | 总收入、总支出、结余卡片 | P0 | 与流水汇总一致 |
| F-02 | 仪表盘 | 最近账单列表（时间倒序） | P0 | 展示分类、金额、记录人、时间 |
| F-03 | 仪表盘 | 成员头像墙 + 每人笔数与收支配比 | P0 | 与成员流水一致 |
| F-04 | 记账 | 收入/支出切换、金额、分类、记录人、备注 | P0 | 入库成功并出现在列表 |
| F-05 | 分类 | 支出：餐饮、购物、交通、教育、医疗、娱乐、其他；收入：工资、奖金、投资、红包、其他 | P0 | 与代码常量一致 |
| F-06 | 成员 | 列表、每人笔数与收支配比、最近流水摘要 | P0 | 与 DB 一致 |
| F-07 | 统计 | 支出分类饼图、收入来源饼图、成员支出柱状图 | P0 | 无数据时有空态 |
| F-08 | 同步 | 多端数据一致；列表可实时更新 | P0 | Realtime 开启时验证 |
| F-09 | 删除 | 支持删除单条流水（需确认） | P1 | 删除后各页一致 |
| F-10 | UI | 移动端视口、橙粉渐变、圆角卡片、页面过渡动画 | P0 | 主观验收 + 窄屏可用 |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | MVP 数据量下首屏与操作流畅；图表在移动端可交互 |
| 安全 | Service Role 仅服务端；anon 仅 RLS 只读；密钥不入库不入前端 |
| 可用性 | 配置错误时有明确提示（SetupPrompt） |

## 6. 里程碑

| 阶段 | 交付 |
|------|------|
| MVP | 当前仓库功能 + Supabase 迁移 + 文档 |

## 7. 风险与待决

|----|------|
