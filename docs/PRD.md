# 产品需求文档（PRD）

> 产品：家庭记账 · 版本：v1.3 · 状态：已实现 · 更新日期：2026-11-16

## 1. 文档信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 家庭记账（温暖小账本） |
| 技术形态 | Next.js 移动端视口 + Supabase（PostgreSQL） |
| 多家庭 | 以 **6 位数字家庭编码** 区分数据；登录页可 **加入已有家庭** 或 **创建新家** |

## 2. 背景与目标

### 2.1 背景

家庭日常收支分散、难以及时对齐；需要一款**多人共用**、**数据云端一致**、**以手机为主**的轻量账本，并支持多个家庭相互隔离。记账之外，布布与一二还希望「这个月还能花多少」有一个共同数字，并用对话助手与大事账本补齐日常以外的场景。

### 2.2 目标

- 进入应用前通过 **家庭编码** 识别当前家庭；支持 **创建新家庭**（名称 + 编码）并默认生成成员 **布布**、**一二**。  
- 展示家庭总收入、总支出与结余；最近账单与成员维度统计；月度/年度**分析页**与统计页**每日趋势**。  
- 快速记账（收入/支出、分类、记录人、备注、发生时间）与图表统计。  
- **小布助手**：可拖动浮动入口，多轮对话记账与本月/本年小结（服务端 LLM）。  
- **大事记账**：与日常流水隔离的大项目支出台账（装修、婚礼等）。  
- 家庭级**自然月支出总预算**，首页 / 统计（月维度）看到「已花 vs 预算」。  
- UI 温暖友好（暖橙奶油、角色插画、悬浮 TabBar）；数据随 **进入页面 / 路由切换** 从服务端载入；**无定时轮询**；读缓存标签失效 + 写操作即时失效；可 **PWA 安装**（manifest + icon）。

### 2.3 非目标

- 桌面端多栏布局、账单导入导出、银行同步。  
- 完整账号体系（手机号/邮箱登录与密码找回）；家庭编码即当前「家庭口令」。  
- 独立开放 REST 对外 API。  
- 公开环境下的创建家庭**高级**风控（验证码、频率限制）——基础审核已落地，可后续加强。  
- **分类预算、大事记账预算、小布播报预算、跨月套用预算**。  
- **复杂预算体系**：零基预算、多币种、信封滚动结转、成员个人私房预算隔离、收入预算编排、强制超支拦截（超预算仅提示，不禁止记账）。

## 3. 用户与场景

### 3.1 目标用户

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 家庭成员 | 如布布、一二（可新建家庭时自动创建） | 随时记账、看汇总、看对方记的账、看本月预算、和大项目花费 |
| 家庭管理员 | 创建新家的用户 | 自定家庭名称与 6 位编码，立即开始使用；设定本月能花多少 |

### 3.2 用户故事

1. 作为**用户**，我希望**用 6 位数字编码进入我的家庭账本**，以便**与他人共用同一套数据**。  
2. 作为**新用户**，我希望**在登录页创建家庭并自动有布布与一二两个记录人**，以便**不用先跑 SQL**。  
3. 作为**家庭成员**，我希望**打开首页就看到总收支、结余和预算进度**，以便**快速了解家庭财务状况**。  
4. 作为**记账人**，我希望**选收入/支出、分类和记录人一键保存**，以便**几秒记完一笔**。  
5. 作为**用户**，我希望**在另一台设备记账后，本机再次进入页面或点刷新能看到更新**，以便**与云端一致**（不保证秒级自动同步）。  
6. 作为**家庭成员**，我希望**为这个月设一个全家支出预算**，以便**对「还能花多少」有共同预期**。  
7. 作为**用户**，我希望**在统计与分析页按日/周/月/年看图表与趋势**，以便**发现开销结构**。  
8. 作为**用户**，我希望**用小布说话就能记账或听本月/本年小结**，以便**少点表单**。  
9. 作为**用户**，我希望**把装修等大项目单独记账并分析**，以便**不和日常流水搅在一起**。  
10. 作为**用户**，我希望**改分类、换主题、点历史备注回填**，以便**账本更贴合自家习惯**。  
11. 作为**用户**，我希望**在本机标明「我是谁」**，以便**记一笔默认选对自己，并在首页看到对方刚记的账**。

## 5. 产品能力地图（已实现）

```text
/login
  加入家庭（仅 active） | 提交创建申请（pending，待审）

MobileShell（底栏：/ · /record · /stats · /members）
  /                 仪表盘 KPI + 预算进度 + 今日小结 + 最近账单
  /record           记一笔
  /stats            区间图表 + 成员明细 + 趋势 + 区间洞察（按周期）
  /stats/analysis   月/年分析
  /stats/member/:id 成员区间明细
  /members          成员墙 + 更多功能入口 + 设置
  /members/settings 「我是谁」/ 编码 / 退出（编码 258099 另见管理后台入口）
  /tools            工具箱
  /tools/budget     本月全家预算（含未设空态说明）
  /tools/events/**  大事记账

/admin/login · /admin · /admin/ops · /admin/households/[id]
                        超管：家庭审核 + 运营概览 + 家庭详情（Astryx）

FloatingChatBot     小布（仅一级 Tab）
```

### 5.1 预算口径（摘要）

- 表 **`budgets`**（`007_budgets.sql`）；Actions `budget.ts`；缓存标签 **`budgets`**。  
- **全家共用**月度总预算；只计日常支出；大事不计；超预算仅提示。  
- 未设：首页/统计轻引导 + 预算页说明用途与示例金额，不制造焦虑。  
- **预算节奏洞察**（首页）：有预算时在进度下展示一句；偏快用日均外推，宽松用剩余÷剩余天；链到 `/tools/budget`。  
- 验收：未设见引导 → 设 3000 花 900 见进度与节奏句 → 80%/超支文案 → 跨月不串 → 大事支出不影响日常进度。

### 5.2 大事与日常

- 日常：`transactions` → 首页 / 统计 / 预算 / 小布快照。  
- 大事：`major_events` + `major_event_expenses` → 仅工具箱大事链路；**不进**家庭总账 KPI 与月预算。

### 5.3 小布

- 每轮结合服务端账本快照；可直接入账；支持本月/本年小结。  
- 历史：`chat_messages` 按家庭隔离。

### 5.4 本机「我是谁」

- 键：`money-record:self-member-id`（设置页选择）；回退键：`money-record:last-record-member-id`（记一笔上次人选）。  
- 记一笔默认记录人：优先「我是谁」→ 上次记账人。  
- 「对方刚记了」：排除本机身份后的最近 1～2 笔；无身份时首页提示去设置。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | MVP 数据量下流畅；统计 Recharts 按需分包；分段 Loading；预算与流水聚合避免多余瀑布请求 |
| 安全 | Service Role 仅服务端；无 anon 读业务表；家庭编码等同口令；LLM 密钥仅服务端 |
| 可用性 | SetupPrompt；登录/创建错误文案；预算未设不制造焦虑；小布失败有可读错误（非裸 JSON） |

## 8. 风险与待决

| 项 | 说明 |
|----|------|
| 公开部署 | 创建申请须后台审核；仍可刷 pending 行，可后续加验证码/限流 |
| 家庭编码泄露 | 获知 **已通过** 编码即可经服务端会话访问该家庭数据 |
| 时区 | `occurred_at` 与自然月边界须与「本月已花」一致 |
| LLM 依赖 | 小布依赖外部模型额度与网络；未配置密钥时助手不可用 |
