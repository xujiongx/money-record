# 产品需求文档（PRD）

> 产品：家庭记账 · 版本：v1.2 · 状态：已实现 · 更新日期：2026-11-16

## 1. 文档信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 家庭记账（温暖小账本） |
| 技术形态 | Next.js 移动端视口 + Supabase（PostgreSQL） |
| 多家庭 | 以 **6 位数字家庭编码** 区分数据；登录页可 **加入已有家庭** 或 **创建新家** |

## 2. 背景与目标

### 2.1 背景

家庭日常收支分散、难以及时对齐；需要一款**多人共用**、**数据云端一致**、**以手机为主**的轻量账本，并支持多个家庭相互隔离。记账之外，布布与一二还希望「这个月还能花多少」有一个共同数字，避免月底才发现超支。

### 2.2 目标

- 进入应用前通过 **家庭编码** 识别当前家庭；支持 **创建新家庭**（名称 + 编码）并默认生成成员 **布布**、**一二**。  
- 展示家庭总收入、总支出与结余；最近账单与成员维度统计。  
- 快速记账（收入/支出、分类、记录人、备注）与图表统计。  
- UI 温暖友好（家用账本纸感：纸底细线、黏土橙实色、衬线标题）；多设备数据以 **进入页面 / 路由切换** 从服务端载入；**无定时轮询**；服务端对成员/流水读接口使用短期数据缓存（标签失效 + 写操作即时失效），非毫秒级推送。  
- 支持家庭级**自然月支出总预算**，在首页 / 统计（月维度）看到「已花 vs 预算」。

### 2.3 非目标

- 桌面端多栏布局、账单导入导出、银行同步。  
- 完整账号体系（手机号/邮箱登录与密码找回）；家庭编码即当前「家庭口令」。  
- 独立开放 REST 对外 API。  
- 公开环境下的创建家庭风控（频率限制、审核）——可后续迭代。  
- **分类预算、大事记账预算、小布播报预算、跨月套用预算**。  
- **复杂预算体系**：零基预算、多币种、信封滚动结转、成员个人私房预算隔离、收入预算编排、强制超支拦截（超预算仅提示，不禁止记账）。

## 3. 用户与场景

### 3.1 目标用户

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 家庭成员 | 如布布、一二（可新建家庭时自动创建） | 随时记账、看汇总、看对方记的账、看本月预算还剩多少 |
| 家庭管理员 | 创建新家的用户 | 自定家庭名称与 6 位编码，立即开始使用；设定本月能花多少 |

### 3.2 用户故事

1. 作为**用户**，我希望**用 6 位数字编码进入我的家庭账本**，以便**与他人共用同一套数据**。  
2. 作为**新用户**，我希望**在登录页创建家庭并自动有布布与一二两个记录人**，以便**不用先跑 SQL**。  
3. 作为**家庭成员**，我希望**打开首页就看到总收支和结余**，以便**快速了解家庭财务状况**。  
4. 作为**记账人**，我希望**选收入/支出、分类和记录人一键保存**，以便**几秒记完一笔**。  
5. 作为**用户**，我希望**在另一台设备记账后，本机再次进入页面或切换 Tab 能看到更新**，以便**与云端一致**（依赖导航刷新与缓存失效；不保证秒级自动同步）。  
6. 作为**家庭成员**，我希望**为这个月设一个全家支出预算**，以便**布布和一二对「还能花多少」有共同预期**。  
7. 作为**用户**，我希望**在首页看到本月已花相对预算的进度**，以便**不用进设置才知道有没有超**。

## 4. 功能需求（已实现）

| 编号 | 模块 | 需求描述 | 优先级 | 验收要点 |
|------|------|----------|--------|----------|
| F-00 | 访问控制 | 无有效家庭会话时中间件跳转 `/login` | P0 | Cookie 为合法 6 位数字方可进首页等 |
| F-00a | 登录 | 输入 6 位编码加入已有家庭 | P0 | 编码在库中存在则进入 |
| F-00b | 创建新家 | 输入家庭名称 + 6 位编码；创建家庭并插入成员布布、一二 | P0 | 编码唯一；成功后自动登录 |
| F-00c | 切换家庭 | 设置页清除会话并回登录页 | P1 | Cookie 与 localStorage 编码清除 |
| F-01 | 仪表盘 | 本月已花为主 KPI；相对上月一句话；收/支/结余次要 | P0 | 按发生时间落在本月 |
| F-01a | 仪表盘 | 今日小结；对方刚记了（非本机上次记账人 1～2 笔） | P1 | 无本人偏好时可不展示「对方」 |
| F-02 | 仪表盘 | 最近账单列表（时间倒序） | P0 | 展示分类、金额、记录人、时间 |
| F-03 | 仪表盘 | 不再放成员墙/入口；成员走底栏 Tab | P1 | `/members` 独立 |
| F-04 | 记账 | 默认：收支、金额、分类、记录人；时间/备注可折叠 | P0 | 写入当前 `household_id`；默认发生时间为此刻 |
| F-05 | 分类 | 支出/收入分类按家庭可配置（增删改查） | P0 | 表 `ledger_categories`；设置页；默认种子见 `lib/ledger/categories.ts` |
| F-06 | 成员 | 列表、每人统计、最近流水摘要 | P0 | 仅当前家庭 |
| F-07 | 统计 | 支出饼图、收入饼图、成员支出柱图；**日/周/月/年**维度（默认**当月**），**前后切换**时间段，**回到今天**重置锚点；按记账时间筛选 | P0 | 切换维度三图同步；无数据空态 |
| F-08 | 同步 | 数据随 **RSC 页面加载与路由切换** 拉取；读列表可经服务端数据缓存（写操作 `revalidateTag` 失效） | P0 | 无客户端定时轮询 |
| F-09 | 编辑 / 删除 | 最近账单左滑露出操作；编辑弹窗改账；删除二次确认 | P1 | 仅当前家庭数据 |
| F-10 | UI | 移动端视口、家用账本纸感、适度圆角、克制动效 | P0 | 窄屏可用 |
| F-11 | 预算设置 | 当前家庭可设置/修改/清空**自然月**全家支出总预算（金额 > 0）；入口 `/tools/budget` | P0 | 仅当前 `household_id`；按月键 `YYYY-MM` 隔离；表 `budgets` |
| F-12 | 预算进度 | 「已花」= 该月日常 `transactions` 支出合计（**不含**大事）；首页 KPI 与统计「月」维度展示进度；≥80% 轻提示、≥100% 超支强调，不拦截记账 | P0 | 未设预算时首页可有轻入口；非月维度提示「预算按月」 |

## 5. 预算说明（已实现）

### 5.1 信息架构

```text
MobileShell
  Home
    KPI「本月已花」
      BudgetProgress?     # 有月预算才显示；否则轻链到设置
  Stats
    月维度摘要
      BudgetProgress
  Members → 更多功能
    /tools/budget         # 设置本月全家总预算
```

### 5.2 数据与口径

- 表 **`budgets`**（`007_budgets.sql`）；读写经 `app/actions/budget.ts`，缓存标签 **`budgets`**。  
- **全家共用**一套月度总预算；只计日常支出；大事支出不计入。  
- **提示不拦截**：超预算仍可记账。  
- 进度与现有暖橙 / 支出红 token 一致。

### 5.3 验收场景

1. 未设预算：首页与现网一致；可从轻入口进入设置并保存。  
2. 设本月预算 3000，日常支出合计 900：进度约 30%，剩余 2100。  
3. 已花到 2400（80%）：接近上限提示。  
4. 已花到 3100：超支展示；仍可再记一笔。  
5. 进入下月：默认无预算；上月进度不串月。  
6. 同月大事花了 5000、日常花了 1000、总预算 3000：进度只认日常 1000。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | MVP 数据量下首屏与操作流畅；统计页 **Recharts 按需分包**；全局与 `/stats` **分段 Loading** 改善 Tab 切换感知；预算进度与流水聚合同请求或可缓存，避免额外瀑布 |
| 安全 | **Service Role 仅服务端**；当前 **无 anon 读业务表策略**；家庭编码等同口令，勿泄露；创建家庭为公开能力，生产需评估风控 |
| 可用性 | 配置错误时有明确提示（SetupPrompt）；登录/创建错误有文案反馈；预算未设置时不制造空状态焦虑 |

## 7. 里程碑

| 阶段 | 交付 |
|------|------|
| v1.1 | 多家庭编码、中间件、登录/创建新家、导航刷新 + 读缓存、文档同步 |
| v1.2 | 月度全家总预算 + 首页/统计进度 + `/tools/budget`（迁移 `007_budgets.sql`） |

## 8. 风险与待决

| 项 | 说明 |
|----|------|
| 公开部署 | 任意访客可创建家庭，可能被刷库；可后续加验证码/审核/关闭注册 |
| 家庭编码泄露 | 获知编码即可通过服务端接口访问该家庭数据（Cookie 会话） |
| 时区 | `occurred_at` 与「自然月」边界需与现有「本月已花」一致（避免预算月与 KPI 月错位） |
