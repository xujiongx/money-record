# 2026-04-08 文档与实现同步

## 范围

对齐当前主分支：**Tab 切换性能**、**统计页 Recharts 按需加载**、**分段 Loading**、**根布局动态策略** 等。

## 实现摘要（供文档交叉引用）

| 主题 | 说明 |
|------|------|
| 数据缓存 | `fetchMembers` / `fetchTransactions` 使用 `unstable_cache`，标签 `ledger`；`requireHouseholdId` 使用 React `cache()` 同请求去重 |
| 失效 | 记账/改账/删账、登录写 Cookie、清除会话时 `revalidateTag("ledger", "max")` + 原有 `revalidatePath` |
| 根布局 | 已移除 `export const dynamic = "force-dynamic"`；需动态的页面仍因 `cookies()` 等为动态渲染 |
| 全局 Loading | `app/loading.tsx`：非统计路由切换时的通用骨架 |
| 统计 Loading | `app/stats/loading.tsx`：仅 `/stats` 的轻量骨架（`StatsChartsSkeleton`） |
| 统计图表 | `StatsChartsGate`（Client）内 `next/dynamic` + `ssr: false` 加载 `StatsCharts`，Recharts 独立分包 |
| 模板 | 已删除 `app/template.tsx`（减少路由切换时模板层 remount） |
