# 2026-04-18 · 账本读缓存与 RSC stale 窗口上调

- 首次：将三处 **`unstable_cache`** 的 **`revalidate`** 从 **120** 提到 **300**（秒），并与 **`experimental.staleTimes.dynamic`** 对齐。
- 后续：再统一到 **3600**（1 小时）；**`staleTimes.static`** 一并 **3600**。
- 再调整：**客户端** `staleTimes` 保持 **3600s**（1h），**服务端** `unstable_cache` 回到 **120s**（2min），软导航轻快、刷新/服务端数据更快对齐 DB。
- 再调整：读缓存与服务端 **`unstable_cache`** 再统一为 **3600s**；首页 **`DashboardClient`** 增加 **「刷新数据」**，调用 **`refreshLedgerReadCache`**（`revalidateTag` + `revalidatePath`）后 **`router.refresh()`**，强制重查库。
- 动态 Tab：底部 **`Link prefetch`** + **`usePrefetchAppTabs`** 首帧立即 **`router.prefetch`**，便于硬刷新后尽快填满客户端 RSC 缓存（与 **`staleTimes.dynamic`** 配合）。

## 品牌、图标与 PWA 元数据

- **`lib/app-branding.ts`**：集中 **`APP_DISPLAY_NAME` / `APP_SHORT_NAME` / `APP_DESCRIPTION`**，供 **`app/layout.tsx`** 与 **`app/manifest.ts`** 引用；改产品名或 slogan 只改此处（及可选 **`AppLogo` 默认 `alt`**）。
- **`app/layout.tsx`**：**`metadata`**（`title`、`description`、`applicationName`、**`appleWebApp`**、**`icons.apple`** → **`/icon.svg`**）、**`viewport`**（**`themeColor`**、`viewportFit` 等）。
- **`app/manifest.ts`**：**`MetadataRoute.Manifest`**；**`start_url: /record`**、**`standalone`**、**`orientation: portrait`**；**`icons`** 与 **`theme_color` / `background_color`** 与壳层橙粉背景一致。
- **`app/icon.svg`**：唯一图标源；**`components/common/AppLogo.tsx`** 登录页展示同源 **`/icon.svg`**。
