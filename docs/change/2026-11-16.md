## 实现要点

### 预算 v1

- 迁移：`supabase/migrations/007_budgets.sql`
- Actions：`app/actions/budget.ts`（标签 `budgets`）
- UI：`/tools/budget`；首页 KPI / 统计「月」维度 `BudgetProgressCard`
- 口径：已花 = 该月日常 `transactions` 支出；≥80% / ≥100% 轻提示，不拦记账
- 返回：预算页 `SubpageHeader historyBack`，从首页直达时一键回首页
- 首页本月总览：拉开区块留白；去掉与上月对照进度条（只留一句对比）；对照文案不再重复大数字；预算以分隔带嵌入
- 首页角色插画：文档流右对齐 + 固定 rem 负边距踩进本月卡片（`perch` 用 clamp）；不再 absolute/%，避免各机挡标题不一致；今日小结不内嵌插画

### 家庭创建审核

- 迁移：`supabase/migrations/008_admin_and_household_status.sql`（`households.status`、`admin_users`）
- Actions：`app/actions/admin.ts`；`createHouseholdAndLogin` 写 **pending**、不写家庭 Cookie
- UI：`/admin/login`、`/admin`（待审 + **已有家庭**列表）；设置页仅编码 **`258099`** 显示入口
- 通过 → `active`；**拒绝 → 删除家庭**（释放编码）
- 中间件保护 `/admin`；管理会话 Cookie 与家庭编码分离
- Actions：`fetchActiveHouseholds` 供管理页浏览已通过家庭
- 登录/创建：审核中不再用红色报错，改为等待提示（含编码、下一步说明）；`setHouseholdSession` / `createHouseholdAndLogin` 返回结构化结果
- **部署修复**：Vercel 构建偶发 `next/font/google queries have exactly one entry`（Turbopack 解析 Google kit URL）；升级 **Next / eslint-config-next → 16.4.6**；`engines.node` 固定 **`26.x`**（Vercel 已停用 20.x）
- **字体**：去掉 `next/font/google`（Noto SC / Nunito 拉 gstatic 在国内与局域网手机易超时）；改用 `@fontsource/nunito` + `@fontsource/geist-mono` 自托管，中文用系统字体栈

### 我是谁 + 预算空态（高价值低成本）

- 设置页 **「我是谁」**：`SELF_MEMBER_KEY`；记一笔默认优先本人；首页「对方刚记了」按本人排除；无身份时轻提示去设置
- 预算未设：首页/统计引导文案说明用途；`/tools/budget` 空态给示例金额与进度说明
- **PRD** 补 F-06b / 用户故事 / 能力地图 / 非目标与审核表述对齐
