## 目标（对齐 PRD）

按 [SSGOI × Next.js](https://ssgoi.dev/docs/frameworks/nextjs) 为移动端账本补上路由级页面过渡，提升 Tab 切换与详情钻入的体感，同时保持底栏 / 渐变头 / 小布入口不闪动。

## 范围

| 类型 | 内容 |
|------|------|
| 包含 | 安装 `@ssgoi/react`；Provider + RouteBoundary；接入 layout / MobileShell；fade + drill 规则 |
| 不包含 | Hero / Sheet 等更复杂过渡；改业务页面结构 |

## 技术设计摘要

- **`app/ssgoi-provider.tsx`**：`Ssgoi` + 规则  
  - `/stats/**`（除 `/stats`）、`/members/**`（除 `/members`）→ **`drill()`**  
  - 其余 `/**`（低优先级）→ **`fade()`**（底部 Tab 互切）
- **`app/ssgoi-route-boundary.tsx`**：`key={pathname}` + `data-ssgoi-transition={pathname}`
- **持久壳**：仅 `main` 内 children 进 boundary；nav / gradient / FloatingChatBot 留在 `MobileShell`
- 外壳增加 **`relative z-0 overflow-x-clip`**，满足离开页裁切与堆叠上下文
