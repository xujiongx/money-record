## 技术设计摘要

### SSGOI

- **`app/ssgoi-provider.tsx`**：`Ssgoi` + 规则  
  - `/stats/**`（除 `/stats`）、`/members/**`（除 `/members`）→ **`drill()`**  
  - 其余 `/**`（低优先级）→ **`fade()`**（底部 Tab 互切）
- **`app/ssgoi-route-boundary.tsx`**：`key={pathname}` + `data-ssgoi-transition={pathname}`；页层实色底 `#fff7f5` + 自带渐变头，避免过渡半透明叠层透出旧页
- **持久壳**：仅页面内容进 boundary；nav / FloatingChatBot 留在 `MobileShell`（渐变头随页层走，不再全局固定一份）
- `MobileShell` 外包一层 **`relative z-0 overflow-x-clip`**，满足离开页裁切与堆叠上下文

### 成员列表可发现性

`app/members/page.tsx`：

- 增加区块标题「家庭成员」+ 副文案「点击查看全部账单」
