# 2026-05-21 · 备注历史（localStorage）

## 范围

记账页与编辑流水弹窗：备注成功保存后写入本地历史；输入框下方按当前分类展示历史标签，两行横向滑动，点击回填。

## 实现

| 文件 | 说明 |
|------|------|
| `lib/ledger/note-history.ts` | `money-record:note-history`；条目 `{ category, note, usedAt }`；同分类同文案去重置顶；最多 **150** 条 |
| `components/features/record/NoteHistoryTags.tsx` | 按分类过滤；奇偶分两行；`overflow-x-auto` 横向滑动；点击 `onSelect` 回填 |
| `RecordForm.tsx` / `EditTransactionModal.tsx` | 保存成功且备注非空时 `pushNoteHistory`；挂载 `NoteHistoryTags` |

## 行为说明

- 仅展示**当前选中分类**下的历史备注；切换分类标签列表随之变化。
- 空备注不写入历史；编辑/新建保存成功后写入。
- 历史仅存本机 `localStorage`，不随家庭编码同步，切换设备不共享。
