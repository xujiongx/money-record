## 4. 小布浮窗：移动端滚动与高度及 ChatBotMascot 容器

### 问题

对话面板仅用 `max-h`、中间消息区 `flex-1` 时，在部分移动浏览器上中间区域高度不定，长回复无法在内层滚动，表现为末尾文字被底部输入区挡住。

### 改动（`FloatingChatBot.tsx`）

- 遮罩层增加 `h-full min-h-0`，便于子级用 `max-h-full` 约束在可视区域内。
- 面板使用明确高度 `h-[min(86svh,640px)]`（移动端优先 `svh` 减轻地址栏伸缩），桌面 `sm:h-[min(86dvh,640px)]`，并配合 `max-h-full` 不超过已含 safe-area 的内边距区域。
- 头、错误条、底栏加 `shrink-0`；消息列表保持 `min-h-0 flex-1 overflow-y-auto`，并加 `overscroll-y-contain`、`-webkit-overflow-scrolling: touch`。
- 遮罩 `pt` / `pb` 使用 `max(1rem, env(safe-area-inset-*))`，避免刘海与底部指示条挤压内容。
- 滚到底时机包一层 `requestAnimationFrame`，便于 DOM 更新后再滚动。

### `ChatBotMascot` 与容器

外层 **`span`**（`block min-h-0 min-w-0`）+ 内层 **`svg`**（`h-full w-full`、`meet`），`className` 打在 **`span`**。**FAB** 为渐变圆形按钮 + 内高光 + 形象 **`absolute inset-0`**；**标题 / 空态** 为白底圆角容器 + 形象 **`inset-0`** 铺满。

## 5. 月度小结提示词（按本月日历进度）

### 问题

用户触发「本月小结」的日期未必是月末，原提示词易诱导模型按「整月已定稿」写总结。

### 改动（`app/actions/mistral-chat.ts`）

- 新增 **`buildMonthSummaryTimeContext(anchor)`**：写入提问日、当月总天数与当前日序号、日历进度约百分比、阶段标签（月初/上旬/中旬/下旬/临近月末）及分阶段措辞约束。  
- **`MONTHLY_SUMMARY_SYSTEM`** 与 **`generateMonthlySummaryAction`** 的 user 段补充：须读时间语境；开篇/结尾区分月初、月中、临近月末；金额仍统称「截至目前」并与摘要一致。

## 7. 小布对话按家庭持久化（`chat_messages`）

### 范围

按 **当前 Cookie 家庭** 将小布与用户的一问一答存入 PostgreSQL，打开浮层时回填历史（最近 300 条）。

### 数据库

- 迁移 [`003_chat_messages.sql`](../supabase/migrations/003_chat_messages.sql)：表 **`chat_messages`**（`household_id`、`role`、`content`、`created_at`），RLS 开启、无 anon 策略。

### 实现

- **`app/actions/chat-history.ts`**：`fetchChatMessagesAction`、`persistChatExchangeAction`；依赖 **`requireHouseholdId`**（自 `ledger.ts` 导出）。  
- **`FloatingChatBot`**：每次打开浮层拉取历史；`mistralChatAction` / `generateMonthlySummaryAction` 成功后再 **`persistChatExchangeAction`**；落库失败时提示「未写入历史」。
